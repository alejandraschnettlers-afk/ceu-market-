CEU Market · Web v4 · Bienvenida + cookies + código por correo con Gmail (14/11/2026)
=====================================================================================

CÓMO FUNCIONA
Escribes tu correo @usp.ceu.es -> la web le pide a Netlify que envíe un código de 6 cifras
desde el Gmail del grupo -> lo escribes -> eliges facultad -> entras (la sesión dura 30 días).
El código caduca a los 10 minutos y nunca se ve en el navegador: lo comprueba Netlify.

QUÉ HAY EN ESTA CARPETA
- public/                 La web (index.html, app.js, inicio.html)
- netlify/functions/      enviar-codigo y verificar-codigo (lo que corre en Netlify)
- netlify/lib/            La lógica del código firmado
- netlify.toml            Le dice a Netlify qué publicar
- package.json            Dependencia para enviar correos (nodemailer)

IMPORTANTE: arrastrar la carpeta a Netlify NO vale, porque así Netlify no ejecuta las funciones
que envían el correo. Hay que subirla a GitHub y conectar GitHub con Netlify (pasos 2 y 3).

PASO 1 · Gmail del grupo (5 min)
1. Usad un Gmail del grupo (por ejemplo, uno nuevo tipo ceumarket.grupo@gmail.com).
2. https://myaccount.google.com/security -> activad la "Verificación en 2 pasos".
3. https://myaccount.google.com/apppasswords -> nombre: CEU Market -> Crear.
   Google os da una contraseña de 16 letras. Copiadla (no es la contraseña normal del Gmail).

PASO 2 · Subir a GitHub (5 min)
1. https://github.com -> cread cuenta si no tenéis -> "New repository" -> nombre: ceu-market -> Create.
2. En el repositorio vacío: "uploading an existing file".
3. Arrastrad TODO lo que hay dentro de esta carpeta (public, netlify, netlify.toml, package.json,
   package-lock.json) y pulsad "Commit changes".

PASO 3 · Conectar con Netlify (3 min)
1. https://app.netlify.com -> Add new site -> Import an existing project -> GitHub.
2. Autorizad y elegid el repositorio ceu-market. No cambiéis nada de la configuración -> Deploy.

PASO 4 · Las 3 variables secretas (3 min)
Netlify -> vuestro sitio -> Site configuration -> Environment variables -> Add a variable:
   GMAIL_USER          el Gmail del grupo (ej. ceumarket.grupo@gmail.com)
   GMAIL_APP_PASSWORD  la contraseña de 16 letras del paso 1
   CODE_SECRET         una frase larga inventada, de 30 caracteres o más (no la compartáis)
Después: Deploys -> Trigger deploy -> Deploy site (las variables solo se aplican al volver a publicar).

PASO 5 · Probar
Abrid la web de Netlify, entrad con vuestro correo @usp.ceu.es y escribid el código que os llega.
El correo llega desde el Gmail del grupo con el nombre "CEU Market".

PARA HACER CAMBIOS
Editad o subid los archivos en GitHub: Netlify republica la web solo en un minuto.

SI ALGO FALLA
- "El envío de códigos aún no está configurado" -> faltan las variables o no habéis vuelto a publicar.
- "No hemos podido enviar el correo" -> la contraseña de aplicación está mal copiada o el Gmail
  no tiene activada la verificación en 2 pasos.
- "La web tiene que estar publicada en Netlify desde GitHub" -> se subió arrastrando la carpeta.
- No llega -> mirad spam / correo no deseado (el correo del CEU puede filtrar remitentes nuevos).
- Gmail permite unos 500 envíos al día: de sobra para el prototipo.

Nota para la memoria: es un prototipo. En un producto real se añadiría un límite de intentos por
correo y se guardarían los usuarios en una base de datos.
